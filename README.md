# Hanger's Closet - Web

A modern responsive React web application powered by **Vite**, **pnpm**, **Beer CSS** (Material Design 3), and **React Router v7**.

## Features

- ⚡ **Vite + React + TypeScript** for fast development and type safety
- 🍺 **[Beer CSS](https://www.beercss.com/)** + **Material Dynamic Colors** for lightweight Material Design 3 UI components and icons
- 🧭 **React Router v7** with structured routing across 3 primary pages:
  - **Home** (`/`)
  - **Inventory** (`/inventory`)
  - **Settings** (`/settings`)
- 📱 **Mobile-First Responsive Layout**:
  - Sticky header bar with integrated 3-tab navigation
  - Touch-optimized tap targets (≥ 48px)
  - Seamless light/dark theme toggle powered by Beer CSS
  - Safe area inset handling for mobile viewports

## Getting Started

### Prerequisites

- Node.js (v18+)
- pnpm (v9+ / v12+)

### Development

```bash
pnpm dev
```

### Production Build

```bash
pnpm build
```

### Preview Build

```bash
pnpm preview
```
